Lesson 5: CSS Selectors

What are CSS Selectors?

CSS selectors are used to “find” or “select” the HTML elements that you want to style.

They are divided into six main types:

  1. Class selector
  2. Element (Tag) selector
  3. ID selector
  4. Universal selector
  5. Group selector
  6. Attribute selector

Element Selector

Selects specific HTML elements such as <p>, <div>, or <h1> and applies CSS to them.

p { color: blue; } → styles all paragraph elements.

ID Selector

  • Used to apply a style to one unique element on a page.
  • Defined by a hash symbol (#).
  • Uses the id attribute in HTML.
  • Best for unique elements like a header, footer, or navigation bar.
#title { font-size: 30px; color: red; }
<h1 id="title">Welcome</h1>

Universal Selector

The universal selector selects every single HTML element on the page.

* { margin: 0; padding: 0; box-sizing: border-box; }

Group Selector

Used to select multiple elements and apply the same style to all of them at once.

h1, h2, h3 { color: blue; }

Attribute Selector

Used to style elements based on specific HTML attribute values.

input[type="text"] { background-color: yellow; }

When to Use Each Selector

  • Class Selector (.) — Use when styling multiple elements that share the same style, even if they are different tags.
  • ID Selector (#) — Use for styling a single unique element (like a banner or footer).
  • Element Selector — Use to style all occurrences of a specific tag (like all paragraphs or headings).
  • Universal Selector (*) — Use when you want to apply styles to every element, such as resetting default margins or padding.
  • Group Selector — Use when different elements share the same styling to avoid repetitive code.
  • Attribute Selector — Use when you need to target elements based on their attributes (like input fields or links).

What I Have Learned

I learned that selectors are used to target specific HTML elements. They help apply styles to certain parts of a webpage, like a paragraph, heading, or class.
