Lesson 6: Setting Dimensions & Pseudo-Classes

CSS Dimensions

CSS can be used to control dimensions such as visibility, width, and height of HTML elements.

Property Definition Example
visibility Controls if an element is visible or hidden.
  • visibility: visible; → default (visible)
  • visibility: hidden; → hidden but still takes up space
  • visibility: collapse; → removes row/column for tables or flex items
width Indicates the width of an element. width: 200px;
height Indicates the height of an element. height: auto;
line-height Controls the line spacing between text lines. line-height: 12px;
max-height Sets the maximum height of an element. max-height: 12px;
min-height Sets the minimum height of an element. min-height: 12px;
max-width Sets the maximum width of an element. max-width: 12px;
min-width Sets the minimum width of an element. min-width: 12px;

Pseudo-Classes and Links

Pseudo-classes are predefined selectors that define a special state of an element. They are not user-defined and start with a colon (:).

Anchor tags (<a>) have four common pseudo-classes:

  • :link — for unvisited hyperlinks.
  • :visited — for visited hyperlinks.
  • :hover — for when the mouse is hovered over the link.
  • :active — for when the link is clicked.
  • :focus — for when the link or element is focused (clicked or tabbed into).

The correct order is called LVHA — Link, Visited, Hover, Active.

Example:

a:link { color: blue; }
a:visited { color: purple; }
a:hover { color: green; }
a:active { color: red; }
a:focus { background-color: yellow; }

Note: The :hover pseudo-class should always be placed after the :link pseudo-class for it to function properly.

Pseudo-Classes Beyond Links

Pseudo-classes can also be used on other HTML elements such as images, paragraphs, and divs. They can make your webpage more interactive — for example, by changing background colors or borders when hovered.

p:hover { background-color: lightblue; }
img:hover { border: 3px solid blue; }

What I Have Learned

I learned how to set the width and height of elements and use pseudo-classes like :hover or :active to add special effects when users interact with a webpage.
