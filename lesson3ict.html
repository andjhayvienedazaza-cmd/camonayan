Lesson 3: Display Property

Display Property

The CSS display property allows you to control how an element is displayed.

Block Level Elements

Block level elements take up as much space as possible by default. They start on a new line and stack vertically. Examples include:

  • <p>
  • <ol>, <ul>, <dl>
  • All heading tags
  • <article>, <section>, <div>

Inline Level Elements

Inline elements display in a line without forcing the next text to a new line. Examples include:

  • <a>
  • <strong>, <em>, <b>, <i>, <q>, <mark>
  • <span>

Note: Inline elements cannot contain block-level elements.

Correct Example

<p><em>An emphasized paragraph.</em></p>

<p><em>Another emphasized paragraph.</em></p>

Div Tag

  • Div divides the contents of a web page into individual sections.
  • It allows you to apply styles to different sections of your webpage.
  • It is a block-level element and usually applied to block HTML content.
  • Provides line spacing before and after a block element.

Span Tag

  • Span is used to emphasize words or sentences within a paragraph.
  • It is an inline element used for smaller parts of content.

Span and Div Tags

  • They have no default styling.
  • Used with CSS to format parts of the content.
  • <div> has line breaks before and after; <span> does not.

What I Have Learned

I learned that display properties control how elements appear on a page. For example, block, inline, and none change how items are shown or hidden.
