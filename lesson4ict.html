Lesson 4: CSS Rule and Class Selector

CSS Rule

A CSS rule has two main parts: a selector and one or more style declarations.

The basic format of a CSS style rule is as follows:

For Inline Style Rule:

<tag style="style declaration">
<tag style="prop1:value; prop2:value; prop3:value;">

For Document-level and External Style Sheets:

selector { style declarations }
selector { prop1:value; prop2:value; prop3:value; }

Style Properties

Properties in CSS are grouped into six categories:

  • Fonts
  • Colors and Backgrounds
  • Text
  • Boxes and Layout
  • Lists
  • Tag Classifications

Classes

What are Classes?

  • A class is a user-defined selector used to apply style rules to specific HTML tags.
  • They help control individual element formatting.
  • They are reusable and flexible, allowing multiple elements to share the same style.
  • Classes are defined by a dot (.) before the class name.

How to Define and Use Classes

Two ways to write class selectors:

  1. Element followed by a dot and the class name — applies only to that specific element type.
  2. Dot followed by a class name — can apply to any element.
p.golden { color: blue; } → Element + class selector
.sodapop { color: red; } → Class selector only

You can apply a class to an element using the class attribute:

<p class="golden">This text is blue.</p>

Note: One element can have multiple classes, and one class can be applied to many elements.

Class Selector

Element + Class Selector (element.classname): A style applied only when both the element and class match.

Why Use Element + Class Selectors?

  • Class selector (.classname): Reusable across many elements.
  • Element + Class selector (p.classname): Gives precise control over styling a specific type of element.

What I Have Learned

I learned that CSS rules are made up of a selector and a declaration block. The declarations include properties and values that define how an element should look.
